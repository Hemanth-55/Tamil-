# Session start

1. `git pull --rebase` so the notes are current.
2. Read `notes/session-log.md` (top 3 entries), `notes/projects.md` and `notes/decisions.md`.
3. Reply to Hemi in 3–5 short lines (simple English / Tanglish):
   - what happened last session
   - open next steps
   - ask what he wants to work on today
