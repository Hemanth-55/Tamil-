# Log a decision

- Preference or decision → add a dated line to `notes/decisions.md`
- Project status, link or deadline → update `notes/projects.md` (edit the row; add one if it's new)
- Use one line, in his words. Never store secrets.
- Commit with a clear message. Push now if he asks; otherwise it goes out with the session-end push.
